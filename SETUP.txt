OFFICE TASK REPORTING — V28 FRESH MASTER SETUP
================================================

Purpose
-------
This version disconnects the old hard-coded Master Google Sheet and uses Script Properties for a NEW fresh Master Google Sheet.

Requested Drive structure
-------------------------
My Drive
└── Dashboard Final List
    └── Task Managment Office
        ├── Employee Photos
        └── Employee Google Sheet

Fresh Master Google Sheet
-------------------------
Name: Task Managment Office
Location: Dashboard Final List / Task Managment Office

IMPORTANT: Google Apps Script cannot use the local Windows path "G:\\My Drive\\..." directly. The setup function resolves the same folders by their names inside Google Drive.

ONE-TIME SETUP
--------------
1. Open the Google Apps Script project used by this backend.
2. Replace the existing backend_code.js with the V28 backend_code.js from this ZIP.
3. Save the script.
4. In the Apps Script function dropdown, select:
      setupFreshTaskOffice
5. Click Run.
6. Approve Google Drive/Spreadsheet permissions when Google asks.
7. The function will automatically:
   - create/find Dashboard Final List
   - create/find Task Managment Office
   - create/find Employee Photos
   - create/find Employee Google Sheet
   - create a NEW Master Google Sheet named Task Managment Office
   - create only the required application tabs
   - create the Users header structure with NO users/passwords
   - save the NEW Master Sheet ID and folder IDs in Script Properties
8. The OLD Master Spreadsheet ID is no longer used by this V28 backend.

FRESH USERS
-----------
The new Users sheet is intentionally EMPTY except for headers.
No old User ID/password is copied.
Create the first MasterAdmin/Admin user from your fresh Users sheet or your Admin User Management screen.

Employee-level Google Sheets
----------------------------
Employee backup/data files are created under:

Dashboard Final List / Task Managment Office / Employee Photos

The existing yearly employee-storage logic remains active. Employee files should be maintained year-wise according to the application's annual storage logic.

DEPLOYMENT
----------
After setupFreshTaskOffice() completes:
1. Deploy the Apps Script as a NEW deployment/version.
2. Copy the new /exec URL.
3. Put that URL into the GOOGLE_SCRIPT_URL constant in index.html if the frontend URL changed.
4. Deploy the updated index.html to Vercel/GitHub.

SECURITY NOTE
-------------
Do NOT put MasterAdmin credentials in backend_code.js or index.html.
Credentials belong only in the fresh Users sheet.

OLD SHEET
---------
The old Master Sheet is not deleted by this setup. It is simply disconnected from this backend by replacing the MASTER_SPREADSHEET_ID Script Property.
This is intentional so no old testing data is accidentally destroyed.
